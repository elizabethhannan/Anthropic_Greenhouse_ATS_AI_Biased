## Preserved research limitations

- Phase 4 prediction is **NOT_ESTIMABLE**: only 3 exact role/month cells matched dated postings and known-sex observed hires, below the prespecified cell and class thresholds; grouped cross-validation was not estimable.
- Phase 5 is exploratory and coverage-limited: observed start months are April–July 2026; August and September are unavailable, not zero. Forward comparisons have few month pairs and the +2 month comparison is deferred. Aggregate co-movement is not causal or person-level evidence.
- Observed outcome counts (606 MALE, 276 FEMALE, 213 UNKNOWN) describe the observed dataset, not a complete hiring funnel. No individual posting-to-hire linkage is claimed.
